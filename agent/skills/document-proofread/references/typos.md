# 公文高频错别字与易混词对照表

校对错别字时对照本表。判定的首要依据是词义与语境，本表仅供高频提示，不得机械替换。

## 一、同音/近音易混词

| 错误写法 | 正确写法 | 辨析要点 |
|---------|---------|---------|
| 布署 | 部署 | 布置安排；"部"不可写作"布" |
| 帐目 / 记帐 | 账目 / 记账 | 与财物记录有关用"账"；"帐"专指帐篷、纱帐 |
| 销脏 / 窝脏 | 销赃 / 窝赃 | 与财物相关用"赃" |
| 凭添 | 平添 | 凭空增加；"平"不可写作"凭" |
| 迁徒 | 迁徙 | 迁移；"徙"与"徒"形近易混 |
| 防碍 | 妨碍 | 干扰阻碍；"妨"读 fáng |
| 即然 | 既然 | 连词；"既然"不可写作"即然" |
| 既便 | 即便 | 让步连词"即便"；"既"与"即"易混 |
| 故然 | 固然 | 承认事实；"固"不可写作"故" |
| 决对 | 绝对 | 完全、肯定 |
| 急待 | 亟待 | 紧急等待；"亟待"语义更急切，且"急"作副词时用"亟" |
| 严竣 | 严峻 | 严肃厉害；"峻"不可写作"竣" |
| 严竣（完成义） | 竣工 | 工程完毕用"竣" |
| 交纲 | 交往 | 书面语误用 |

| 帐篷 | 帐篷 | 野外遮蔽物用"帐" |
| 装潢 | 装璜 | 装饰用"潢" |

| 精萃 | 精粹 | 精华用"粹" |

## 二、形近字易混

| 误写 | 正确 | 说明 |
|------|------|------|
| 已→己 | 按语境区分 | "己"（自己）已闭口；"已"（已经）半开口；"巳"（地支）全开口 |
| 未→末 | 按语境区分 | "未"（没有）；"末"（尽头） |
| 戍→戌→戊 | 按语境区分 | 点戍横戌空心戊 |
| 燥→躁 | 干燥用"燥"；急躁用"躁" |
| 滥→槛 | 泛滥用"滥"；门槛用"槛" |
| 棘→辣 | 棘手用"棘"（丛生小枣树）；辣椒用"辣" |
| 肆→肄 | 放肆用"肆"；肄业用"肄" |
| 毖→毙 | 惩前毖后用"毖"；毙命用"毙" |
| 简练→简炼 | 简练 | 文笔用"简练" |
| 锻炼→锻练 | 锻炼 | "炼"为冶炼锤炼 |
| 炼油→练油 | 炼油 | "炼"为加工油料 |
| 装订→装钉 | 装订 | "订"为装订成册 |
| 妥贴→妥帖 | 妥帖 | 妥当合适用"帖"；"贴"为贴近、补贴 |

## 三、多字漏字常见类型

1. 单位全称中漏字（如"发展和改革委员会"漏"改革"）。
2. 固定搭配漏字（"进一步"漏"一"）。
3. 文号、日期中漏数字。
4. 领导职务与姓名之间漏字。

> 校对多字漏字以逐字通读为最可靠方法，不可依赖机器查找。

## 四、校对原则

- 以《现代汉语词典》（第7版）为用字规范依据。
- 专有名词（机构名、地名、人名、文件名）以权威出处为准，查不到用【待核实】。
- 拿不准时宁可标注【疑似误字】，不强行替换。
