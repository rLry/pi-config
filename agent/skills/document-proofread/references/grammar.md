# 常见语病类型与修改示例

校对语法环节时，识别并修正以下语病类型。每条均给出正误对照，举一反三。

## 一、搭配不当

| 类型 | 错误示例 | 正确示例 |
|------|---------|---------|
| 动宾搭配 | 提高…水平到… | 提高…水平；提升…能力 |
| 动宾搭配 | 加强…建设力度 | 加强…建设 / 加大…建设力度 |
| 主谓搭配 | 措施…取得显著成效 | 措施…取得成效 / 工作取得成效 |
| 修饰语与中心语 | 非常的重要事项 | 十分重要的事项 |
| 量词搭配 | 一件会议 | 一次会议 |

## 二、语序不当

- 多层定语的顺序：表领属 → 表时间/处所 → 表数量/指称 → 动词性/形容词性 → 名词性。
  - 错误：我市的安全生产工作会议于2026年召开第一次。
  - 正确：我市2026年第一次安全生产工作会议于……召开。
- 多层状语顺序：表目的/原因 → 表时间 → 表处所 → 表情态 → 表对象。
- 关联词位置：分句主语相同，关联词在主语的后面；分句主语不同，关联词在主语前面。
  - 错误：不仅这项工作完成了，而且……（主语不同，"不仅"应前置：不仅这项工作……）
  - 正确：这项工作不仅完成了，还……

## 三、成分残缺或赘余

- **缺主语**：错误"通过……，使……"句式（滥用介词导致缺主语）。
  - 正确改法：删"通过"或删"使"，保留一个主语。
- 缺谓语：名词短语直接成句。
- 缺宾语：动词后缺名词性成分（如"进行了""实现了"后无宾语）。
- 成分赘余："非常至关重要""大约…左右""接近…左右""涉及到""付诸于""亲眼目睹""凯旋归来"等。

## 四、结构混乱（句式杂糅）

- 错误：本着以……为原则。
- 正确：本着……的原则 / 以……为原则。
- 错误：由于……的原因，造成……
- 正确：由于…… / 因为……造成……（二选一）。
- 错误：根据……的要求来看。
- 正确：根据……的要求 / 从……来看。

## 五、不合逻辑

- 概念并列不当："各部门及处室"（上下位概念并列）。
- 主客倒置：错误"对这一做法，他表示赞成"语义可通，但"对此项工作深表支持"优于"对此支持此项工作"。
- 前后矛盾："大致完成"与"全部完成"并存；"已全部到位"又"个别尚未到位"。
- 因果倒置、强加因果。
- 时态矛盾："将于2026年1月完成"（将来时）与"已全部完成"（完成时）同现。

## 六、用词不当

- 书面语与口语混用："这活儿"应为"这项工作"。
- 词性误用："很模范"（名词误作形容词）应为"很模范的表现"或"起到了模范作用"。
- 近义词误用："截止"与"截至"：
  - "截至"后接时间点，表"到…为止"："截至2026年6月底"。
  - "截止"本身不带宾语："报名截止"；表"到…截止"时用"截止到/于"："报名截止到6月30日"。
- "其他的问题"中"其他"（指代不确）多用于书面；"其它"现在多规范为"其他"（包括事物）。

## 七、公文特定语病高频点

1. **"的、地、得"误用**："进行了全面的检查"（的，定语后）；"全面检查了"（地，状语后）；"检查得很全面"（得，补语后）。
2. **一逗到底**：整段仅用一个句号，靠逗号串联所有分句。应在完整句义结束处用句号。
3. **"一是…二是…三是…"后标点**：分句间用分号，末项后接句号或冒号。
4. **"进一步""切实""不断加强"等虚义堆砌**：无实义加强时删除（属 P3 建议性，不强制）。
5. **主宾不一致**："实现…的总体目标"作"以…为目标"时前后呼应一致。
6. **被动句滥用**：公文宜多用主动句，慎用"被"字。

## 八、校对语法环节工作顺序

1. 逐句通读，先断句确定句子主干（主谓宾）。
2. 检查主干成分是否完整、搭配是否恰当。
3. 检查枝叶（定状补）语序与层次。
4. 检查关联词、介词的使用与位置。
5. 检查逻辑关系（因果、并列、转折）是否成立。

> 语法修改须保留原意，涉及政策、数据、结论的表述如有疑义，仅标注【待核实】，不擅自改写。
