# 公文格式规范要点

本文件是校对"格式规范"环节的依据摘要，依据《党政机关公文格式》（GB/T 9704-2012）和《党政机关公文处理工作条例》（中办发〔2012〕14号）整理。本文件聚焦"文字层面的格式要素"校对；字体字号、页边距等排版参数不属本 skill 范围，需要修改时改用 `docx` skill。

## 一、发文字号

- 组成：发文机关代字 + 年份 + 顺序号，如"××发〔2026〕3号"。
- 年份用六角括号〔〕，内为公元年份（全称，如"2026"），不写"26年"。
- 顺序号不加"第""号"以外的字，不写"0号"。
- 常见错误：使用小括号（）代替六角括号、年份省略前两位、顺序号带"第"字。

## 二、标题三要素

- 标题 = 发文机关名称 + 事由 + 文种，如《××县人民政府关于进一步加强安全生产工作的通知》。
- 标题中除法规、规章名称加书名号外，一般不加标点。
- 批转（转发）性文件标题较长时，可适当简化（如只保留被转发文件的发文机关与文种）。
- 标题回行时词意完整、排列对称、长短适宜。

## 三、主送机关

- 顶格排布，回行时仍顶格，末尾用冒号。
- 同级别机关之间用顿号，不同级别机关之间用逗号（如"各县（区）人民政府，市政府各部门："）。
- 应使用规范化简称，机关名称要准确、不随意增减"市""县""省"等层级词。

## 四、正文开头与结尾固定格式词

### 常见开头句式
| 文种 | 规范开头 |
|------|---------|
| 通知 | "为……，现将有关事项通知如下" |
| 报告（汇报类） | "现将有关情况报告如下" |
| 请示 | "因……，现请示如下" |
| 函 | "现将……函告如下" / "为……，现函商如下" |
| 批复 | "你（单位）《关于……的请示》收悉。经研究，现批复如下" |
| 意见 | "为……，现提出如下意见" |

### 常见结尾固定词
| 文种 | 规范结尾 |
|------|---------|
| 通知 | "特此通知。" |
| 报告 | "特此报告。"（述职报告类可"以上报告，请审阅"） |
| 请示 | "妥否，请批示。" / "妥否，请批复。" |
| 函（商洽） | "专此函商，盼复。" / "特此函告。" |
| 函（答复） | "特此函复。" |
| 批复 | "此复。" |
| 意见 | "请结合本地实际认真贯彻落实。" |
| 决定 | "本决定自发布之日起施行。" |

校对要点：结尾词须与文种匹配（"请示"用"特此通知"即属文种-结语错配）；句号使用规范；"妥否，请批示"后不加其他文字。

## 五、附件说明

- 位置：正文之下、发文机关署名之上，左空二字编排"附件：××××"。
- 附件名称后不加标点；有两个以上附件时用阿拉伯数字编号（1. 2. 3.）。
- 附件名称较长回行时，与冒号后的首字对齐。

## 六、成文日期

- 用阿拉伯数字将年、月、日标全，如"2026年8月12日"。
- 年份不得略写；"0"开头月份按规范写法（如"2026年1月"）。
- 成文日期在发文机关署名之下，右空四字编排；联合行文时以最后签发机关日期为准。

## 七、印发机关和印发日期

- 印发机关左空一字，印发日期右空一字，阿拉伯数字标注。
- 版记置于公文最后一面。

## 八、其他格式要素速查

- **签发人**：上行文应标注签发人姓名，居右空一字；与发文字号同处一行。
- **密级和保密期限**：涉密公文应标注，如"绝密·长期"；本 skill 遇涉密内容即停止处理。
- **紧急程度**："特急""加急"，编排在版心左上角。
- **份号**：涉密公文应标注份号（6位阿拉伯数字）。
- **附注**：公文印发传达范围等说明，加括号标注于成文日期下一行。
- **印章**：单一机关行文时，印章端正、居中下压成文日期；联合行文时各机关印章均须盖齐。
- **抄送机关**：标注于版记首行，一般用"抄送："领起，机关间用逗号，回行时与冒号后首字对齐，末尾标句号。

## 九、层级序号

第一层"一、"，第二层"（一）"，第三层"1."，第四层"（1）"。

- 序号层级不得跳用（如一后直接接"1."）。
- 第一层后用顿号，第三层后用圆点，第二层、第四层不加标点。
- 同一文种内序号格式须全文统一。

## 十、校对核查清单（格式要素完整性）

- [ ] 发文字号：机关代字、〔年份〕、序号三要素齐全且格式正确
- [ ] 标题：三要素齐全、文种正确、不加多余标点
- [ ] 主送机关：称谓准确、层级词无误、标点规范
- [ ] 正文开头、结尾固定格式词与文种匹配
- [ ] 附件说明位置、编号、标点规范
- [ ] 成文日期格式正确、与署名关系正确
- [ ] 签发人、密级、紧急程度等要素与行文方向匹配
- [ ] 层级序号使用规范、全文统一
