# 年鉴改稿示例

以下示例展示改稿前后的对照效果，用于校准改写风格。示例均为演示用途，非真实县情。

## 示例一：生猪产业（综合类条目）

**输出样式（对话内表格，修改处加粗）：**

| 原文 | 修改后 |
| --- | --- |
| 我县始终坚持把生猪产业作为农业支柱产业来抓，积极打造现代农业产业体系。2025年，多措并举推进生猪产能调控基地建设，持续加强养殖监管，推动生猪产业健康发展。全年生猪出栏21万头，年末生猪存栏4.2万头，全县规模养殖场达到337家，其中龙头企业代养场5家。生猪产业继续保持平稳运行态势，产业效益显著提升，为全县农民增收作出了重要贡献。 | **2025年，南部县**推进生猪产能调控基地建设，稳固生猪产能，优化产业发展。全年生猪出栏21万头，**年末存栏4.2万头**，**共有**规模养殖场337家，其中龙头企业代养场5家。 |

**修改要点说明：**

1. 首句明确主体"南部县"和年度"2025年"（规则二）。
2. 删除"始终坚持""积极""多措并举""持续加强""健康发展""平稳运行""显著提升""重要贡献"等评价性、过程性表述（准则一、规则一）。
3. "达到337家"改为"共有……337家"，措辞更平实（规则四）。
4. 同类数据（规模养殖场与龙头企业代养场）合并为一个分句置于段尾（规则四）。
5. "年内"类时间用"全年""年末"固化表述（规则三、十四）。

## 示例二：水务工程（动态性条目）

**输出样式（对话内表格）：**

| 原文 | 修改后 |
| --- | --- |
| 为保障灌区育秧、泡田栽秧、渗灌和抗旱用水，县水务局今年实施了升钟水库右总干渠的掺灌补水工程，通过科学调度、精心组织，有力保障了农业灌溉和人畜用水，获得了群众的一致好评。 | **2025年，县水务局**实施升钟水库右总干渠掺灌补水工程，保障灌区育秧、泡田栽秧、渗灌和抗旱用水，以及农业灌溉和人畜用水。 |

**修改要点说明：**

1. 明确主体"县水务局"和年度（规则二、十三）。
2. 保留"保障"等中性目的描述（规则十一）。
3. 保留专业术语"掺灌补水"，不简化为"增灌"（规则十二）。
4. 删除"科学调度、精心组织""有力""获得群众一致好评"等过程性、评价性表述（准则三）。
5. "今年"改为具体年度（时间表述规范）。
6. 原文未提供工程完工时间与效益数据，如必要可标注【待核实补充】（规则十）。

## 示例三：荣誉称号（述而不论）

**输出样式（对话内表格）：**

| 原文 | 修改后 |
| --- | --- |
| 我县成功创建国家园林县城，创建工作成效显著，极大地提升了城市形象和品位，人民群众的获得感、幸福感显著增强。 | **2025年，南部县**创建国家园林县城，**获住房和城乡建设部命名**。 |

**修改要点说明：**

1. 删除"成功""成效显著""极大地提升""获得感、幸福感显著增强"等评价性表述（准则三）。
2. 荣誉记明评选部门（语体风格规范："经评比获得的荣誉，应记明评选部门"）。
3. 假设评选部门为住房和城乡建设部，若原文未说明评选部门，应标注【待核实补充】。
