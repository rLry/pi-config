# 资料整理为基础志稿细则

将原始资料（采访记录、档案文件、会议记录、部门工作总结等）整理为符合志书编纂要求的规范文稿。

## 整理目标

使零散原始资料成为"横不缺要项、纵不断主线"、具备"资政、存史、教化"价值的志稿基础文本，做到资料性与著述性统一。

## 整理步骤

### 第一步：通读与鉴别

- 通读全部原始资料，识别资料性质（第一手/第二手、权威性如何）。
- 资料须真实、准确，经过鉴别、考证、核实（《地方志书质量规定》第二十三条）。
- 有歧义但不可或缺的资料，多说并存（第二十三条）。
- 注重使用原始资料；资料具有代表性、权威性（第二十五条）。

### 第二步：去粗取精

- 删除口语化表达、重复内容、无关细节。
- 删除无志书价值的铺垫性文字、常规工作活动、共性管理内容。
- 删除过程性描写、评价性文字。
- 保留核心事实要素：时间、地点、人物（单位）、事件、结果（数据、成效）。

### 第三步：规范化处理

- **文体**：现代语体文记述体；不抒情、不描写、不议论；用陈述句。
- **人称**：第三人称；政区、机构直书其名，不用"我市""我局"等；人物直书姓名，不加"同志""先生"，必须说明身份的首次出现时在姓名前冠以职务（职称）。
- **名称**：统一人名、地名、机构名；机构等专有名称首次出现用全称，简称括注于全称之后。
- **时间**：统一时间表述为公元纪年；不用"今年""最近""目前"等不确切时间概念；年份不简称；清代及清以前纪年括注公元。
- **数字**：统一数字用法（统计数字、年、月、日、年龄、百分比等用阿拉伯数字）；数据前后一致，统计口径清楚。
- **术语**：专业术语首次出现时加注（以专业辞典正条为准，不乱改提法内涵）。

### 第四步：重新组织

- 按时间或逻辑顺序重新组织。
- 分层次分段，同类归并。
- 借鉴志书体例分层：篇—章—节—目，或按事物门类归类。
- 合理组织使反映事物发生、发展过程的资料连贯、系统（第二十四条）。

### 第五步：标注与说明

- 资料来源注明出处（引文和重要资料注明出处，第四十条）。
- 无法核实的标注【待核实】。
- 数据截止时间不明的动态数据，标注【待核实补充】。

## 输出格式

1. **整理后文稿**：符合志书行文规范的完整文稿（可附篇目结构建议）。
2. **整理说明**（附于文稿后）：
   - 资料来源（档案、采访、会议记录等）及出处。
   - 整理思路（如何归类、如何组织时序/逻辑）。
   - 删除内容的类别（口语化表达、重复内容、无关细节等）。
   - 待核实事项清单。

## 检查要点（整理完成后复核）

- 是否保留全部核心事实要素（时间、地点、人物、事件、结果）。
- 是否有人称、称谓违规。
- 时间表述是否全部规范（公元纪年、无模糊时间词）。
- 数据是否前后一致、口径清楚。
- 专业术语是否加注。
- 是否残留口语化、评价性、宣传性文字。
