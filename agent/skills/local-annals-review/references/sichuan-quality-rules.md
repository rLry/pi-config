# 《四川省市县志质量标准细则》要点摘录

- **来源**：《四川省市县志质量体系建设纲要（试行）》（川志函〔2023〕118号）附件2
- **发布机关**：四川省地方志工作办公室，2023年12月28日印发
- **说明**：发布通知目录中附件名为《四川省市县志编纂标准细则》，正文标题为《四川省市县志质量标准细则》，内容一致。

## 总体要求

志书质量的总体要求：观点正确，体例严谨，分类科学，内容全面，特色鲜明（重点突出），记述准确，资料翔实，文风端正，印制规范。

## 一、观点

### （一）编纂思想

以马克思列宁主义、毛泽东思想、邓小平理论、"三个代表"重要思想、科学发展观、习近平新时代中国特色社会主义思想为指导，全面贯彻落实习近平文化思想，坚持辩证唯物主义和历史唯物主义的立场、观点和方法，坚持马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合。遵循《中共中央关于党的百年奋斗重大成就和历史经验的决议》，全面反映中国特色社会主义事业的历程和成绩，正确反映历史发展中的曲折和问题，体现时代特色和精神风貌。

### （二）内容把握

志书不得含有下列内容：背离《中华人民共和国宪法》确定的基本原则的；危害国家统一、主权和领土完整的；泄露国家秘密、危害国家安全或损害国家荣誉和利益的；煽动民族仇恨、民族歧视，破坏民族团结，或侵害民风民俗和习惯的；宣扬邪教、迷信、赌博、暴力的；侮辱或诽谤他人，侵害他人合法权益的；危害社会公德或民族优秀文化传统的；法律、法规和国家规定禁止的其他内容的。涉及国家安全、社会稳定等重大问题，法律、法规及政策未作规定的，经由有关部门审查把关，正确把握记述尺度。

志书编纂，涉及时政和社会生活、法律法规、民族宗教、港澳台和领土主权、国际关系等方面的词语使用，要严格遵守新华社发布的《新华社新闻信息报道中的禁用词和慎用词（2019年2月修订）》。

## 二、体例

坚持志体：横排门类、纵述史实、述而不论。体例科学、规范、严谨。

### （一）体裁运用要求

志书体裁主要指述、记、志、传、图、表、录七种，应**七体并用，志为主体**：

1. **述**——三级述设置完整。概述不能写成概况，要能总括地情、提炼精华、沟通联系、彰明因果、评量得失。
2. **记**——大事、要事、新事、特事突出。大事记以编年体为主、纪事本末体为辅，做到"大事突出、要事不漏、新事不丢、特事不缺"，时间、地点、人物要素齐备。专记选题从严控制，不可过多过滥。
3. **志**——据事直书，叙而不论、述而不作；以时为序，不采用倒叙、插叙、补叙；记述要见人见事，"六要素"齐全（人物、时间、地点、事件的原因、发展变化和结果）；各级文件可作为资料但不能直接入志，入志须转换文体。
4. **传**——人物真实，坚持"生不立传"原则，忌将"传"写成人物履历。
5. **图**——图照丰富、图说完整；图注要素齐全；一般不用人物标准照。
6. **表**——补充文字，设置适度；设计合理、要素齐全、内容准确、不与正文简单重复。
7. **录**——保存资料，设置灵活；对正文有拾遗补缺作用。

### （二）体式格式要求

- **体式**：大篇体（地理、政治、经济、军事、文化、社会、生态等大类）、中篇体、小篇体，结合本地实际采用。
- **格式**：章节体、纲目体、类目体、卷目体、条目体、章节与条目结合体等，采用适当格式，有利于全面反映地情、处理共性事物和个性事物。

## 三、内容

### （一）内容记述范围

反映本行政区域内**自然、政治、经济、文化、社会、生态**的历史和现状。大致涵盖：建置、自然环境、资源、人口；中国共产党、人民代表大会、人民政府、政治协商会议、民主党派、群众组织、公检法司、军事；城乡建设、生态环境建设、交通、邮电信息、公用事业；农业、工业、建筑业、服务业、经济管理；教育、科学技术、文化艺术、新闻出版、广播影视、卫生与健康、体育；人民生活、人力资源和社会保障、民政、民族、宗教、风俗、方言；人物。

### （二）内容记述要求

内容完整，横不缺要项，纵不断主线；详略得当，重点突出；反映事物基本特征，记述完整有深度。

1. 记述单元要清晰。记述单元一般是节、目、子目，层次清晰，不宜过多。
2. 记述要素要齐全。事物开端、发展、现状等要素不可或缺。
3. 内容竖写要以时间为序。
4. 内容要综合记述，不记流水账。
5. 选取人文内容入志，采用"以事系人"的记述方法。

## 四、资料

1. 资料真实、准确：经过鉴别、考证、核实；有歧义但不可或缺的资料，多说并存。
2. 资料全面、系统：反映事物发生、发展过程的资料连贯、系统。
3. 资料具有代表性、权威性。
4. 资料来源：重视官方网站、市县地方史/地方党史/政协文史、地方统计年鉴、地方综合年鉴、档案资料；口述资料应与相关文字资料互相佐证，单一资料使用时用注释交代来源。

## 五、篇目

1. 篇目应达到：记述事物全面完整，整体布局合理，结构严谨，归属得当，层次分明，排列有序，设置匀称，重点突出，详略得当。
2. 分类标准：依据事物的基本属性（不是部门、程序、形式）作为分类的基本标准；以合乎科学分类和社会分工实际为原则；事以类从，科学分类；分类标准要符合社会分工实际。
3. 篇目设置基本原则：
   - 记述事物的门类要齐全（"横不缺要项"是对篇目制定的要求，"纵不断主线"是对内容记述的要求）。
   - 篇目结构要严谨，层次清晰，篇、章、节及节下层级规范。
   - 记述事物的排列要有序，篇与章、章与节、节与目之间是上下层相辖的领属关系，不能排在同一层次。
   - 类目的升降格使用要得当，为反映时代特点和地方特色可"提级升格"。

## 六、记述

- 区域界限明确，以本行政区域为记述范围，越境不书。交代背景、反映与区域外横向对比和联系，不视为越境而书。
- 时间界限明确，不随意突破上限和下限，严格控制上溯或下延；为保持记述完整，个别情况可适当上溯或下延。
- 续修志书处理好与前志的衔接，注意对前志的拾遗补缺、订讹正误。
- 寓观点于记述中，述体中的必要议论适度，不空泛。
- 志书中同一名称、史实、数据、时间、度量衡、术语的表述，前后一致。
- 内容记述不机械重复，交叉记述的事物从不同角度记述，或此详彼略，或用互见法。
- 生不立传。在人物传、人物简介、人物表以外记述人物，以事系人、人随事出。人物传记述传主的生卒年月、籍贯（出生地）、主要经历、典型事迹、个性特征、社会评价等；人物简介略记人物履历及主要事迹；人物表要素不缺。
- 图的制作规范，要素齐全，包括必要的图题、图例、注记和制图者。照片主题明确、图像清晰，注明时间、地点、事物、需要说明的人物的位置及身份、拍摄者等。

## 七、行文

### （一）文风严谨简洁、朴实通俗

1. 使用规范汉字，用词概念准确，符合现代汉语语法规范；使用口语、方言、土语、俗语适当，不滥用时态助词，慎用评价词语；不用模糊、空泛词句；文字不浮夸，不滥用形容词，言简意赅，讲究文采，修饰得当；**杜绝半文半白、文白夹杂**的文字记述。时间、空间概念表述准确具体，指代明确。
2. 行文严谨、朴实、简洁、流畅。无知识性和常识性错误。不乱改科学定律、理论概念、政治术语、历史典籍、名家名言的提法和内涵等。
3. 使用规范的现代语体文记述，不用总结报告、新闻报道、文学作品、教科书、论文等写法。

### （二）称谓名称使用准确

1. 除引文和特殊情况外，以第三人称记述，不使用第一人称；专有名称使用全称，简称括注于全称后；简称、缩略语符合现代汉语规范，不产生歧义。
2. 不同时期的国家、团体、机构、职务等名称，均用当时名称；历史朝代名称使用规范通称，以新版《现代汉语词典》附录的中国历代纪元表为准。
3. 今地名使用各级政府审定的标准地名；历史地名使用当时名称，括注志书时限内名称；涉及其他行政区域地名的，明确行政隶属关系；跨区域名称和数据以国家有关部门公布的为准。
4. 人物直书姓名，不冠褒贬词语，不在姓名后加身份词；必须说明身份的，首次出现时在姓名前冠以职务（职称）。
5. 外国国名和常见地名、人名、党派、政府机构、报刊等译名，以新华通讯社译名为准；没有译名的，首次使用译名时括注外文全称。
6. 生物、矿物名称使用学名；涉及本地生物名称的，首次出现时采用二名法，括注本地俗名。

### （三）时间表述准确

1. **历史纪年**：中华民国以前用帝王年号纪年、农历纪日月，括注公元纪年月日；同一帝王年号在同一实写类目中多次出现的，公元纪年只在首次出现时括注。中华民国时期使用民国纪年，民国纪年用阿拉伯数字书写；民国纪年在同一实写类目中不足一年的，括注首次出现的年份，其余年份不括注；民国时期一般用公元纪日、月。中华人民共和国成立后一律用公元纪年，公历纪日月。
2. **公历纪年**：公历世纪、年代、年、月、日和时刻均使用阿拉伯数字书写，年份书写用全数（不得省略前两位数字）。
3. **含日月简称的词组**：含有日月简称表示事件、节日和其他意义的词组用汉字，用间隔号"·"将表示月份和日子的数字隔开，并外加引号，避免歧义。
4. **不使用不确切的时间概念**：除引文外，不使用时间代名词，如"今年""前年""上月"等，也不使用"最近""不久以前""多年来""目前""现在""近年来""已经""即将"等模糊时间概念。

### （四）数字和量的运用与书写准确

1. 统计数据的使用符合国家统计法律、法规有关规定，数据定义、含义、统计口径和计算方法清楚准确，不错用、滥用。统计数据以国家统计部门公布的法定数据为准；统计部门没有统计的，采用业务主管部门的统计数据。
2. 数字书写方式按《出版物上数字用法的规定》（GB/T15835-2011）执行，并保证全书一致。
3. 计量单位名称、符号的运用，按照《量和单位》（GB 3100-3102-93）执行。

### （五）图表制作规范

1. 涉及党和国家领导人的图片，按《关于严格审核期刊封面刊登党和国家领导人图片的通知》（新出报刊﹝2001﹞141号）要求严格执行送审制度。
2. 入志图照要按出版要求清绘；图注要素齐全；无损害人物形象的画面；著作权问题获得使用授权。
3. 含有国界和省界的地图严格执行《地图管理条例》，履行测绘管理部门报批手续；物产、资源图等使用国家测绘部门的底图绘制；地图注明比例尺；文中图统一编号。
4. 表格包括表序、表题、表体和必要的表注等；表题的时间、范围、主体内容和表格性质等要素齐全；全书表格样式、编号统一。

## 八、出版

- 符合国家关于出版管理法律、法规及相关规定；民族自治地方用本民族语言文字出版的志书符合民族语言文字出版物管理规定；电子介质志书符合电子出版物管理规定。
- 版面格式规范，装帧美观大方；采用16开本（889×1194mm），文字横排；封面书名采用印刷体，不用个人题签。
- 编纂校对符合国家关于图书质量管理的规定，全书差错率不超过万分之一。

## 九、质量管控程序（附件3《四川省市县志质量管控程序》要点）

### 质量管控形式

通过自审和他审形式。志稿完成总纂后，主编（总纂）组织编纂人员对志稿进行自审；自审修改后进行他审，主要包括初审、复审、终审验收程序。

### 各阶段主要任务

1. **自审**：把好政治关；把好资料关（重点资料是否有遗漏、入志资料是否真实可靠、资料使用是否合理）；把好体例关（篇目设计、体裁运用、行文笔法是否符合志体规范）；把好语言关（文风是否端正，是否存在虚文浮语、文白相杂、滥用简称等情况，是否合乎语法规范）；把好保密关（根据国家保密各项规定做好志稿审定工作）。
2. **初审**：对政治观点、体例结构、记述内容、史实数据、行文规范等进行全面审查。须组织有相关行业和部门专家参加的志稿评议会。
3. **复审**：审查志稿是否符合宪法和保密、统计、档案等法律法规的规定；是否符合党和国家的民族、宗教、军事、外事政策；是否全面、客观地反映本行政区域自然、政治、经济、文化、社会、生态的历史与现状。志稿涉及保密的内容，由同级保密部门审查，不能认定的事项报上一级保密部门审查。须组织有同级政府领导参加的志稿评审会。
4. **终审验收**：着重把好政治关和体例关。须组织地方志工作部门以及保密、统计、档案、历史、法律、经济、军事、外事、文化等方面专家参加的终审会，有需要的还应邀请民族、宗教、外事等方面专家参加。终审通过修改完善后提交验收，验收通过后由上级人民政府批准进入出版。

### 审查验收标准（11条）

1. 观点正确：以习近平新时代中国特色社会主义思想为指导；坚持实事求是，坚持辩证唯物主义和历史唯物主义；严格遵循宪法和保密、统计、档案等法律法规；符合党和国家的民族、宗教、外事、军事等政策。
2. 符合志体：述、记、志、传、图、表、录等体裁并用，以志为主；横排纵写，直陈其事，述而不论，寓观点于记述中。
3. 内容全面系统：横不缺要项，纵不断主线；主体资料齐全，重大史料无遗漏；体现时代特点、地方特色。
4. 重点突出，详略得当：反映事物本质，体现事物发展规律，不记流水账或大跨度跳跃式记述，无资料汇编痕迹，资料性和科学性统一。
5. 结构得当：篇目设置符合现代科学分类与社会分工实际，门类合理，归属得当，层次分明，排列有序，特色突出；标题以事命题，简明规范，准确涵盖记述内容；各部分之间无机械交叉重复。
6. 求实存真：资料真实，经过鉴别、考证、核实，时间、地点、人物（单位）、事实、数据准确。
7. 记述准确：区域、时间界限明确，注意对前志的拾遗补缺、订讹正误；记述事物要素不缺，寓观点于记述之中；概述中必要议论适度，不空泛。
8. 行文规范：除引文外，均采用规范的现代汉语（书面语）记述体，行文严谨、朴实、准确、简洁、流畅，符合国家有关出版物行文规定；无总结报告、新闻报道、文学作品、教科书、论文等写法。
9. 配图贴切：图像真实，主题突出，要素齐全；构图严谨，配置得当；资料性强，存史价值高。
10. 送审稿规范：达到齐、清、定标准。齐：凡例、目录、正文、图、表、照片、编后记等齐全；清：志稿字迹和图片清晰，装订成册；定：送审稿必须是经同级人民政府审查后批准上报的志稿。
11. 出版：符合相关规定和要求，版面美观大方，编纂校对符合国家关于图书质量管理的规定。
