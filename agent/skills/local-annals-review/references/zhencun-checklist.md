# 南部县镇村志书对照自查清单（参考）

- **来源**：南部县镇村志书自查对照清单（用户提供，2026年6月）
- **用途**：镇村志初审（自审）、复审依据。各志书修编团队以此清单为初审依据逐项审查修改；镇村成立志书审查小组以此为复审依据，分工分项验收。经初审、复审并修改定稿的志书，按程序申报终审。
- **送审要求**：送审稿电子稿需提供 word 版本，达到齐、清、定要求，目录与正文一致。纸质版需与电子版内容一致，打印清晰，装订成册。

## 一、志书体例结构

1. 内容全面不缺项。
2. 领属关系正确。
3. 篇目顺序正确。
4. 章下无题小序完整。
5. 章节篇幅比例相对平衡。
6. 正文各级标题与目录一致。

## 二、志书观点

1. 坚持辩证唯物主义和历史唯物主义的立场、观点和方法。
2. 遵循宪法和法律、法规的规定，符合党的方针政策。
3. 全面反映发展中国特色社会主义事业的历程和成就。
4. 正确反映历史发展中的曲折和问题。

## 三、志书内容

1. 以本行政区域为记述范围，越境不书。
2. 时间界限明确，不随意突破志书的上限和下限。
3. 纵述史实，不断时线。
4. 内容记述不机械重复。
5. 内容无机构内事信息。
6. 内容不空泛，不拼凑。
7. 不漏记国家重大政策的落实。
8. 史实正确，不错记。

## 四、志书语言

1. 使用规范的现代语体文记述，流畅无病句。
2. 语言朴实，不用总结报告、新闻报道、文学作品、教科书、论文等写法。
3. 语言严谨不夸大、不杜撰，不添加个人主观评论。
4. 语言简洁不繁冗，不修饰，不"穿靴戴帽"。
5. 以第三人称记述，不用第一人称。
6. 不滥用"着""了""过"时态助词。
7. 不使用"上世纪""近年来""现在""已经""目前"等不确定时间词语。
8. 理论概念、政治术语、历史典籍、名家名言表述规范。
9. 机构、法律、文件、会议等规范使用全称、简称。
10. 历史朝代名称规范。
11. 今地名使用标准地名。
12. 人物直书姓名，不加身份词。
13. 生物、矿物名称，使用学名。
14. 同一名称、事实的表述前后一致。

## 五、大事记

1. 大事收录符合标准。
2. 大事全面涵盖自然、政事、经济、文化、社会、民生等。
3. 重大节点事件不漏记、不错记。
4. 时间断限与凡例一致。
5. 叙事完整简洁，不口语化。

## 六、人物

1. 【人物】一章只分【人物传略】【人物简介】【人物列表】。
2. 人物收录符合标准。
3. 人物传记、简介符合体例，有事迹具体、准确。
4. 人物分类列表不杂乱，不混入【人员列表】。
5. 全志所涉人物姓名、职务准确。

## 七、志书图照

1. 图照主题明确，有存史价值，图像清晰。
2. 照片无广告色彩。
3. 图片说明规范，有时间、地点、事件、重要人物的位置及时任职务等。
4. 除人物传记、人物简介外无人员标准像。
5. 图、照紧随相关正文之后，与正文内容一致。
6. 不使用网络图片、越境图片，不人工修改图片。
7. 不未经批准使用国家领导人照片。
8. 地图经国家测绘地理信息部门审定，有审图号、并注明比例尺。

## 八、志书表格

1. 表格紧随相关正文之后。
2. 内容准确，不与正文简单重复或自相矛盾。
3. 表格标题、表头规范。数据表敞开式，文字表封闭式。
4. 不滥收表格。
