# 志稿内容审查要点

依据《地方志书质量规定》（中指组字〔2008〕3号）及地方志编纂规范，对志稿进行内容审查。输出格式：逐条列出意见，每条含【位置】【问题类别】【问题描述】【修改建议】。

## 一、政治性审查

### 检查要点

1. **指导思想符合性**：是否符合大政方针。记述社会主义时期内容，应体现社会主义时代精神风貌，全面反映发展中国特色社会主义事业的历程和成绩，正确反映历史发展中的曲折和问题（《地方志书质量规定》第六条）。

2. **禁止内容**（《地方志书质量规定》第七条）：志稿不得含有下列内容——
   - 反对宪法确定的基本原则的；
   - 危害国家统一、主权和领土完整的；
   - 泄露国家秘密、危害国家安全或者损害国家荣誉和利益的；
   - 煽动民族仇恨、民族歧视，破坏民族团结，或者侵害民族风俗、习惯的；
   - 宣扬邪教、迷信、赌博、暴力的；
   - 侮辱或者诽谤他人，侵害他人合法权益的；
   - 危害社会公德或者民族优秀文化传统的；
   - 法律、法规和国家规定禁止的其他内容的。

3. **敏感内容处理**：涉及国家安全、社会稳定等重大问题，法律、法规及政策未作规定的，应经由有关部门审查把关，正确把握记述尺度（第七条第二款）。

4. **民族、宗教、涉外、保密表述**：是否准确、规范、得体。

5. **历史人物事件评价**：是否与中央精神一致，是否符合党的历史决议和中央有关评价口径。

6. **时政用语规范**：涉及时政和社会生活、法律法规、民族宗教、港澳台和领土主权、国际关系等方面的词语使用，是否严格遵守《新华社新闻信息报道中的禁用词和慎用词（2019年2月修订）》（《四川省市县志质量标准细则》一（二））。

7. **敏感内容来源**：是否注明来源。

### 问题描述示例

- "对××事件的评价使用了未经中央认可的表述，与党的历史决议口径不一致。"
- "涉密数据（××指标）未作脱密处理，可能违反保密规定。"
- "对少数民族风俗习惯的记述存在不当表述。"
- "涉外事项记述超出公开报道口径，未注明来源。"

## 二、事实准确性审查

### 检查要点

1. **时间**：年、月、日是否准确；是否使用"今年""最近""目前"等不确切时间概念；年份是否简称（"95年"应为"1995年"）；纪年方式是否符合规范（清代及清以前帝王年号纪年括注公元，民国纪年括注公元，中华人民共和国成立后公元纪年）；生卒年之间的连接号是否用一字线"—"。

2. **地点**：今地名是否使用各级政府审定的标准地名；历史地名是否使用当时名称并括注志书下限时名称；跨区域名称和数据是否以国家有关部门公布的为准（第三十二条、第三十三条）。

3. **人名**：是否直书姓名、不冠褒贬词语、不加身份词；需要说明身份的，首次出现时在姓名前冠以职务（职称）（第三十四条）。

4. **职务、机构名称**：机构名称是否用全称（简称括注）；不同时期名称是否用当时名称（第三十条、第三十一条）。

5. **数据一致性**：同一数据在志稿不同位置是否一致；前后有无矛盾；数据定义、含义、统计口径和计算方法是否清楚、准确，是否错用滥用（第三十九条）。

6. **数据来源**：统计数据是否以国家统计部门公布的法定数据为准；统计部门没有统计的，是否采用业务主管部门的统计数据（第三十九条）。

7. **资料核实**：资料是否经过鉴别、考证、核实；有歧义但不可或缺的资料，是否多说并存（第二十三条）。

8. **引用可查性**：引文和重要资料是否注明出处；注释是否符合学术规范、便于查找原文（第四十条）。

### 常见问题

- 数据前后不一致（同一指标不同章节数值不同）。
- 人名、职务写错或未用全称。
- 时间表述模糊或纪年换算错误（如清代纪年未括注公元）。
- 引文无出处、无法查证。

## 三、全面性审查

### 检查要点

1. **内容完整性**：横不缺要项，纵不断主线（第十四条）；是否遗漏重大事件、重要事物；反映本行政区域内自然、政治、经济、文化、社会、生态的历史和现状（《四川省市县志质量标准细则》三）。
2. **篇章均衡**：各篇章篇幅、详略是否均衡；详略得当、重点突出（第十四条）。
3. **特色反映**：是否充分反映时代特征和地方特色（或行业特色、民族特色）。
4. **体裁运用**：体裁运用是否得当，以志为主；述、记、志、传、图、表、录七体并用（《四川省市县志质量标准细则》二（一））；篇目设置门类齐全、结构严谨、排列有序、类目升降格得当（《细则》五）。
5. **记述方法**：记述单元（节、目、子目）清晰；竖写以时间为序；综合记述不记流水账；人文内容采用"以事系人"（《细则》三（二））。
6. **断限处理**：时间界限是否明确，是否随意突破志书上下限，上溯或下延是否控制（第十六条）。
7. **续修衔接**：续修志书是否处理好与前志的衔接，是否注意对前志的拾遗补缺、订讹正误（第十六条第二款）。

### 常见问题

- 缺要项（如缺建置沿革、缺人物、缺重大事件）。
- 某篇章过于单薄，某篇章过于臃肿。
- 地方特色内容反映不足。
- 体裁单一（如只述不表、缺图照、缺索引）。

## 四、逻辑性审查

### 检查要点

1. **篇目结构**：篇目设置是否符合"事以类聚""类为一志"的基本要求；科学分类与现实社会分工、全志整体性与分志相对独立性的关系是否处理妥当；归属得当、层次分明、排列有序；类目升格降格是否适当（第十二条）。
2. **标题规范**：标题简明准确、题文相符；同一门类各级标题不重复（第十二条）。
3. **矛盾重复**：同一名称、事实、数据、时间、度量衡、术语的表述是否前后一致（第十八条）；内容是否机械重复；交叉记述的事物是否从不同角度记述或此详彼略，或用互见法（第十九条）。
4. **时间顺序**：竖写单元是否顺叙记事，重点反映事物兴衰起伏；有无插叙、倒叙或记流水账（四川省市县志编纂规范）。
5. **区域界限**：是否以本行政区域为记述范围，越境不书；交代背景、反映与区域外的横向对比和联系是否妥当（第十五条）。

### 常见问题

- 归属不当（同一事物分属两个门类、归属混乱）。
- 标题与内容不符。
- 交叉记述机械重复。
- 时间顺序混乱、倒叙插叙。
- 越境而书（记述本行政区域外事物）。

## 输出模板

```
【位置】第×编第×章第×节目，标题《××××》
【问题类别】事实准确性
【问题描述】××数据在本书第×页为"××"，此处为"××"，前后不一致。
【修改建议】核对原始统计资料，统一为法定数据；如无法核实，标注"待核实"。
```

## 专项审查：大事记

依据《地方志书质量规定》第十一条（记）及镇村志自查清单（见 `zhencun-checklist.md`）：

1. **收录标准**：大事收录是否符合标准，是否"大事突出、要事不漏、新事不丢、特事不缺"（《四川省市县志质量标准细则》二（一）2）。
2. **涵盖范围**：大事是否全面涵盖自然、政事、经济、文化、社会、民生等方面。
3. **重大节点**：重大节点事件不漏记、不错记；重要事项时间、地点、人物（单位）、结果等要素齐备。
4. **时间断限**：大事记时间断限是否与凡例一致。
5. **叙事**：叙事完整简洁，不口语化；以编年体为主、纪事本末体为辅；无须过于翔实（正文已详记的，大事记从简）。
6. **专记**：专记选题从严控制，不可过多过滥。

## 专项审查：人物

依据《地方志书质量规定》第二十条、第二十一条及镇村志自查清单：

1. **章节结构**：【人物】一章只分【人物传略】【人物简介】【人物列表】三个部分（镇村志自查清单）。
2. **收录标准**：立传人物为在本行政区域有重大影响者，以及本籍人物在外地有重大影响者（第十一条（四））；生不立传（第二十条）。
3. **传记、简介体例**：人物传记、简介符合体例，有事迹具体、准确；人物传记述生卒年月、籍贯（出生地）、主要经历、典型事迹、个性特征、社会评价等；简介略记履历及主要事迹，不面面俱到（第二十一条）。
4. **人物列表**：人物分类列表不杂乱，不混入【人员列表】（镇村志自查清单）。
5. **姓名职务**：全志所涉人物姓名、职务准确。
6. **以事系人**：在人物传、简介、列表以外记述人物，以事系人、人随事出（第二十条）。

## 专项审查：图照

依据《地方志书质量规定》第二十二条、第十一条（五）及镇村志自查清单：

1. **图照质量**：图照主题明确，有存史价值，图像清晰；照片无广告色彩（第十一条（五））。
2. **图注说明**：图片说明规范，有时间、地点、事件、重要人物的位置及时任职务等（第二十二条）。
3. **人员标准像**：除人物传记、人物简介外无人员标准像（第十一条（五））。
4. **位置与配合**：图、照紧随相关正文之后，与正文内容一致（镇村志自查清单）。
5. **图片来源**：不使用网络图片、越境图片，不人工修改图片（镇村志自查清单）。
6. **领导人照片**：不未经批准使用国家领导人照片；涉及党和国家领导人的图片严格执行送审制度（《四川省市县志质量标准细则》七（五）1）。
7. **地图**：地图经国家测绘地理信息部门审定，有审图号、注明比例尺；含有国界省界的地图严格执行《地图管理条例》，履行测绘管理部门报批手续（《细则》七（五）3）。

## 专项审查：表格

依据《地方志书质量规定》第十一条（六）、第三十七条及镇村志自查清单：

1. **位置**：表格紧随相关正文之后（镇村志自查清单）。
2. **内容准确**：内容准确，不与正文简单重复或自相矛盾（第三十七条、第十一条（六））。
3. **表格规范**：表格标题、表头规范；数据表敞开式，文字表封闭式（镇村志自查清单）。
4. **表体要素**：表格包括表序、表题、表体和必要的表注等；表题的时间、范围、主体内容和表格性质等要素齐全（第三十七条）。
5. **滥收**：不滥收表格；表的作用是化繁为简、补充文字说明，设置适度（《四川省市县志质量标准细则》二（一）6）。

## 专项审查：体例结构细节（镇村志自查清单）

1. 章下无题小序完整（如有设置，不缺失、不空泛）。
2. 正文各级标题与目录一致。
3. 章节篇幅比例相对平衡。

## 说明

- 审查意见须具体、可操作，避免笼统。
- 引用规范条文时注明出处，不编造条文。
- 涉及【待核实】的事项，须明确指出需要核实的内容和核实渠道。
- 镇村志审查可整体对照 `zhencun-checklist.md` 的八类自查项执行（体例结构、观点、内容、语言、大事记、人物、图照、表格）。
