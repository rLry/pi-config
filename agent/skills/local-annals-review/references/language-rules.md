# 志稿语言规范审查与修改润色细则

依据《地方志书质量规定》（中指组字〔2008〕3号）第七章行文及《四川省第二轮市县级志书编纂规范》等地方规范整理。适用于语言规范审查与语言修改润色两种模式。

## 一、文体要求

- 使用规范的现代语体文、记述体（第二十六条）。
- 不使用总结报告、新闻报道、文学作品、教科书、论文等写法（第二十六条）。
- 不口语、不方言、不俚语、不文言、不文白夹杂。
- 不抒情、不描写、不议论。
- 用陈述句，不用祈使句和疑问句。

## 二、语言风格

- 行文严谨、朴实、简洁、流畅（第二十七条）。
- 褒贬寓于记述，不做直接评价。
- 杜绝空话、套话、废话、浮词。
- 杜绝宣传渲染、广告性文字。
- 判断词、修饰语注意分寸。
- 慎用"国内领先""国际水平""第一"等文字；经评选获得的荣誉，记明评选单位和结果。

## 三、用词规范

### 模糊含混词处理

- 不用含混歧义词，如"上级的指示""由于种种原因""多数人的意见"等。
- 不用模糊、空泛词句（第二十八条），如"进一步加强""取得了显著成效"等。
- 不夸大、不杜撰，不加个人主观评论；流畅无病句；简洁不繁冗，不修饰，不"穿靴戴帽"（镇村志自查清单）。

### 术语规范

- 术语勿错用；专业术语一般以专业辞典正条为准（四川省规范）。
- 不乱改科学定律、理论概念、政治术语、历史典籍、名家名言的提法和内涵（第二十九条）。
- 忌用行业内简称（如业务内部叫法）。

### 铺垫性文字删除

- 删除无志书价值的铺垫性文字、常规工作活动、共性管理内容。
- 如"在××领导下""经过××努力"等套话。

## 四、称谓规范

### 人称

- 以第三人称记述，不用第一人称（第二十七条）。
- 政区、机构、政党、军队等直书其名；不用"我市""我局""我党""我军"等（四川省规范）。
- 可用"全市""县内"等代称，但应保持前后一致（四川省规范）。

### 人物

- 人物直书姓名，不加褒贬之词；不在姓名后加"教授""先生""局长"等身份词（第三十四条、四川省规范）。
- 必须说明身份的，首次出现时在姓名前冠以职务（职称）（第三十四条）。
- 同名人物同时出现时，括注生卒年或出生地，或姓名前加身份词（四川省规范）。

### 名称

- 各种组织、机构、法律法规、文件、会议等专有名称使用全称；使用简称的，在适当地方括注于全称之后（第三十条）。
- 不同时期的国家、团体、机构、职务等名称，均用当时名称（第三十一条）。
- 历史朝代名称使用规范通称，以新版《现代汉语词典》附录的中国历代纪元表为准（第三十一条）。

## 五、时间表述规范

- 时间表述要准确，不用"今年""本月""最近""不久以前""目前"等不确切时间概念（四川省规范）；《四川省市县志质量标准细则》进一步明确：除引文外，不使用时间代名词（"今年""前年""上月"等），也不使用"最近""不久以前""多年来""目前""现在""近年来""已经""即将"等模糊时间概念（《细则》七（三）4）；镇村志自查清单同样禁用"上世纪""近年来""现在""已经""目前"等不确定时间词语（见 `zhencun-checklist.md`）。
- 同一段落中为了节省文字，可用"同年""同月"等（四川省规范）。
- 年份不能简称："1995年"不能写作"95年"；"1992—1994年"不能写作"1992—94年"（四川省规范）；公历世纪、年代、年、月、日和时刻均使用阿拉伯数字书写，年份书写用全数（《细则》七（三）2）。
- 不使用"1980年代"写法，用"20世纪80年代"（四川省规范）。
- 纪年方式：
  - 清代及清以前按朝代帝王年号纪年、农历纪月日、汉字书写，每节（目）首次出现时括注公元纪年，如"清咸丰三年正月初二（1853年2月9日）"（四川省规范）；同一帝王年号在同一实写类目中多次出现的，公元纪年只在首次出现时括注（《细则》七（三）1）。
  - 民国时期采用民国纪年、公历纪月日、阿拉伯数字书写，每节（目）首次出现时括注公元纪年，如"民国15年（1926年）"（四川省规范）；民国纪年在同一实写类目中不足一年的，括注首次出现的年份，其余年份不括注（《细则》七（三）1）。
  - 中华人民共和国成立后使用公元纪年、阿拉伯数字书写（四川省规范）。
- 公元前年份写明"公元前"三字；公元后年份除公元100年以内加"公元"二字外，其余不加（四川省规范）。
- 不简称"建国前""建国后"，用"中华人民共和国成立前""中华人民共和国成立后"（四川省规范）。
- 称"解放"须让读者明了所指地域，如"××镇解放后"（四川省规范）。
- 人物生卒年之间使用一字线"—"，如"毛泽东（1893—1976）"（四川省规范）。
- 含日月简称表示事件、节日的词组用汉字，用间隔号"·"隔开并加引号，如"五四运动""一二·九运动"，避免歧义（《细则》七（三）3）。

## 六、数字规范

以下情况使用阿拉伯数字（四川省规范）：
- 公历世纪、年代、年、月、日、时、分、秒，如"20世纪80年代""1995年7月1日""8时30分20秒"。
- 年龄，如"60岁"。
- 统计数字、倍数、百分比、分数，如"150千克""3倍""12%""1/3"。
- 温度、功率等物理量，如"30℃""25瓦"。
- 引文标注中的版次、卷次、页码。
- 部队代号、证件号码、产品型号和其他序号、代号、代码。

统计数据的使用符合国家统计法律法规；数据定义、含义、统计口径和计算方法清楚准确，不错用滥用（第三十九条）。数字书写方式按《出版物上数字用法的规定》（GB/T15835-2011）执行并全书一致（《细则》七（四）2）。

## 七、量与单位规范

- 使用法定计量单位，度量衡单位使用标准公制（四川省规范）。
- 除公斤、公里、公顷以外的"公字号"单位一律停止使用："公尺""公分"应分别改为"米""厘米"（四川省规范）。
- 长度单位使用米、千米，不用"公里"以外的"公字号"表述；公斤、公里也可用千克、千米表示，但前后一致（四川省规范）。
- 计量单位名称、符号的运用，按照《量和单位》（GB 3100-3102-93）执行（《细则》七（四）3）。
- 中国历史计量单位和外国计量单位（如"斗""石""哩""码""磅"）在引文或叙述历史时可以使用，但应作法定计量单位的换算注释（四川省规范）。

## 八、地名规范

- 今地名使用各级政府审定的标准地名（第三十二条）。
- 历史地名使用当时名称，括注志书下限时名称（第三十二条）。
- 涉及其他行政区域地名的，其行政隶属关系明确（第三十二条）。
- 跨区域的山脉、河流、湖泊、水库、公路、铁路、航线、文物、名胜古迹、重大事件等，名称和数据以国家有关部门公布的为准（第三十三条）。

## 九、译名规范

- 外国国名和常见地名、人名、党派、政府机构、报刊等译名，以新华通讯社译名为准（第三十五条）。
- 新华社没有译名的，首次使用译名时括注外文全称（第三十五条）。

## 十、生物、矿物名称规范

- 使用学名（第三十六条）。
- 记述自然资源涉及本地生物名称的，首次出现时采用二名法，括注本地俗名（第三十六条）。

## 十一、标点符号规范

- 标点符号使用规范、统一，符合国家有关标准（第四十一条）。
- 连接号：人物生卒年、年份区间用一字线"—"。

## 十二、修改润色操作指引

对志稿段落逐条修改润色时：

1. **保留**：核心事实要素（时间、地点、人物、事件、结果）；有信息量的动词结构（如"实现""建成""完成"等成效性动词）；客观描述性词语（如"首次""率先"）；专业术语原貌。
2. **删除**：空话套话废话浮词；宣传渲染、广告性文字；评价性词语（"积极""显著""大力""圆满"等）；铺垫性/常规性/共性内容；无意义连接词（"同时""同步""也""就"等）。
3. **改写**：第一人称改第三人称；口语改书面语；模糊时间改确指时间；简称改全称（或括注）；非标准计量单位改法定计量单位。
4. **每处修改附修改说明**，说明修改类型（删除评价性词语/补全要素/规范称谓/统一计量单位等）及依据（必要时引用条文）。
